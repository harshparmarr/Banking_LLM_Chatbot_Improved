# 🏦 Retail Banking Assistant (FLAN-T5 fine-tuned on Bitext Retail Banking)

Interactive Gradio prototype with three tabs: **Chat**, **Evaluate a response** (live ROUGE / BLEU / METEOR) and **Model report**.

## Files
| File | Purpose |
|---|---|
| `app.py` | The Gradio application |
| `requirements.txt` | Python dependencies |
| `final_model/` | Fine-tuned model + tokenizer + `run_summary.json` + `evaluation_results.csv` (created by the notebook in `MyDrive/banking_llm_outputs/`) |

## Run it
**In Colab (fastest):** open `Prototype_Demo.ipynb`, run all cells.

**Locally:**
```bash
pip install -r requirements.txt
MODEL_DIR=./final_model python app.py
```

**On a Hugging Face Space:** create a Gradio Space, upload `app.py`, `requirements.txt`, this README and the `final_model/` folder
(the Files tab or `huggingface-cli upload` both work), or push the model to a Hub model repo and set `MODEL_DIR` to its id.

> Demo only. Do not enter real account details; answers are generated by a small model and are not financial advice.
